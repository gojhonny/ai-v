## Material gaps and reconciliation

| Issue | Treatment in this study | What would resolve it |
| --- | --- | --- |
| TTS preference versus conversation preference | Separate tables/panels; no shared score conversion. | A new controlled evaluation of the same objective and population. |
| Portuguese availability versus Portuguese quality | Capability notes are separate from preference ranking. | Blind listening and conversation tests with target-language users. |
| Preview benchmark versus current Inworld Flash | Preserve preview label and treat current association as provisional. | Provider/publisher confirmation of the exact evaluated snapshot. |
| Moving Gradium alias | Use `default` as an implementation alias, not an immutable benchmark version. | Record resolved model metadata and evaluate that version. |
| Cartesia overage | Use clearly labeled full-utilization Pro allocation; no inferred overage rate. | Current account-specific overage schedule. |
| Gradium included credits versus top-up | Use the disclosed XS top-up basis; explain the subscription and alternative allocation. | Actual planned volume and final invoice terms. |
| Speechify whitespace and Fish UTF-8 units | Count the same fixture under each billing rule. | Provider usage measurements after text normalization. |
| Soniox and Google token conversions | Explicit approximations; actual generated duration is unmeasured. | Real request usage and generated audio duration. |
| ElevenLabs promotion | Record displayed rate and promotion visibility without applying an extra discount. | Rate applicable to the account when it signs up or renews. |
| Smallest concurrency | Preserve the documentation/pricing discrepancy; no universal capacity promise. | Account-level limits confirmed by the provider. |
| Luna integration and price | Unscored; no invented executable endpoint. | Complete official API contract and tariff. |
| Breeze commercial use and operating cost | Explain model-license restrictions and leave hosted cost unscored. | Appropriate permission and measured deployment costs. |
| OpenAI model-specific Portuguese listing | Mark unverified in this bounded review. | Explicit current support evidence and a language test. |
| SDK dependency/runtime behavior | Syntax and documentation review only; no live or installed-SDK certification. | Version-pinned integration tests with credentials. |

## Research process and stopping rule

Discovery opened the voice-agent reference, the provider-voice leaderboard, and the live-conversation arena. Follow-up reviewed each selected provider's model documentation, pricing, language information, and integration contract. The review was split into three bounded provider families and then reconciled centrally; pricing and benchmark claims affecting the headline results received additional checks.

The study stopped once each selected row had primary model/API/pricing support or an explicit evidence gap. It did not repeat broad market discovery to inflate the row count. No private application materials, customer conversations, or proprietary implementations were used in the public report.
